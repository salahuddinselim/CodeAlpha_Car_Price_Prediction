# CodeAlpha_Car_Price_Prediction

CodeAlpha Data Science Internship — Task 3.

Predicts used-car selling price from features like present price (brand goodwill proxy),
car age, kilometers driven, fuel type, seller type, and transmission, using:
- A `RandomForestRegressor` baseline (scikit-learn)
- A feed-forward neural network trained on GPU (PyTorch + CUDA)

## Run

```
cd CodeAlpha_Car_Price_Prediction
jupyter notebook car_price_prediction.ipynb
```

Select the **Python 3 (CodeAlpha DS)** kernel.

## Dataset

`data/car data.csv` —
[Kaggle: vijayaadithyanvg/car-price-predictionused-cars](https://www.kaggle.com/datasets/vijayaadithyanvg/car-price-predictionused-cars)
